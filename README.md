# Isaak Meakin — Electrical VDC / BIM Portfolio

Snowdon Towers (ST-VDC-01) is an independent educational electrical VDC project using Autodesk sample models as linked building context. It is not for construction.

The site presents purpose and planning, the original electrical model, coordination and troubleshooting, a seven-sheet drawing issue, prefab and modeled quantities, and simulated change FC-01.

## Pages

- `index.html`: project narrative and compact section index.
- `documents.html`: public evidence directory.
- `session-history.html`: selected goals, decisions and outputs from the 30-session tracker.
- `clash-review.html`: final report test summaries.

Serve these static files from the repository root with GitHub Pages. All local asset links are relative to support the `/vdc-portfolio/` path. No build or JavaScript is required.

Original electrical model and project documentation: Isaak Meakin. Linked Autodesk architecture and HVAC provide building context. Early session records are historical and remain unchanged. Native RVT, NWC, NWF and DWG downloads are grouped in the document directory. Original supplied filenames are preserved inside ZIPs; download notes explain reference ownership and relinking. The internal tracker is retained separately.
