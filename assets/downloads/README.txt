Snowdon Towers — ST-VDC-01 — Isaak Meakin
Independent educational electrical VDC project. Not for construction.

The Rev01 electrical model is Isaak Meakin's work. Autodesk's architectural,
HVAC and electrical reference models are supplied building context; the
electrical reference model is not the authored capstone model.

Keep original filenames when extracting. Revit and Navisworks may retain
paths from the original computer. Use Revit Manage Links and Navisworks
file-resolution tools to locate the downloaded references. NWF files store
coordination setup and references; they do not embed the full source models.
Older working files are historical and are separate from the Rev01 issue.

The CAD package includes seven sheet DWGs, one 3D DWG, matching PCP files,
and the two supplied raster image assets. Keep the images alongside the
DWGs and resolve image paths in CAD if necessary. PCP files are companion
plotting settings; their support depends on the CAD software in use.

Prior project checks recorded an RVT reopen, NWC inspection in Navisworks,
and a representative 3D DWG review. Isaak subsequently confirmed the CAD
exports work correctly on October 15, 2026. Packaging verifies file presence
and archive integrity;
it does not add native-application checks or certify a construction design.
